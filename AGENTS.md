# AGENTS.md instructions for MakerLounges

## Project rules

- Prioritize `bun` over `pnpm` over `npm`, and `bunx` over `npx`.
- Always use the `caveman` skill, except when writing `README.md`, `AGENTS.md`, or commit messages.
- Always use the `caveman-commit` skill when creating or updating commit messages.
- Always use the `caveman-review` skill when asked to review code.
- Always use the `create-readme` skill when asked to write or update `README.md`.
- Always use the `create-agentsmd` skill when asked to write or update `AGENTS.md`.
- Always use the `vercel-react-best-practices` skill when the framework is ReactJS or NextJS.

### Issue tracker

Issues are tracked in GitHub Issues for this repo. See `docs/agents/issue-tracker.md`.

### Triage labels
