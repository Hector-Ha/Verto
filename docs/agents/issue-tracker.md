# Issue Tracker

This repo uses GitHub Issues in the private canonical repository as the intended source of truth for work items, PRDs, triage tickets, and implementation tasks.

Canonical issue repo: `Hector-Ha/_verto`

## Workflow

- Use `gh issue list -R Hector-Ha/_verto`, `gh issue view -R Hector-Ha/_verto`, and `gh issue create -R Hector-Ha/_verto` when issue operations are needed.
- Link implementation work back to the relevant GitHub issue whenever possible.
- Do not use the public sanitized repository for internal implementation issues unless explicitly instructed.

## Expected issue types

- Product discovery notes
- PRDs
- Implementation slices
- Bug reports
- Review or triage follow-ups
